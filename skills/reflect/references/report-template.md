# Reflection 보고서 템플릿 및 상세 체크리스트

이 파일은 `/reflect` 커맨드 실행 시 사용하는 보고서 템플릿, 점수 테이블, 상세 체크리스트를 포함합니다.

---

## Self-Critique 상세 검토 항목

### 코드 품질 검증

<!-- CUSTOMIZE: point to your project's coding guidelines -->
**검증 기준**: 프로젝트 코딩 규칙 문서

**자체 검토 프로세스**:
1. **체크리스트 기반 검증**: 코딩 규칙의 모든 항목 대조
2. **위반 사항 문서화**: `{파일명}:{라인} - {위반 내용}` 형식
3. **수정 방법 제시**: 현재 코드 vs 올바른 코드 비교

**검토 범위**:
- 언어 버전 호환성
- SQL 쿼리 규칙
- 아키텍처 패턴 준수
- Frontend 규칙
- 데이터베이스 스키마
- 보안 (XSS, SQL Injection)
- 성능 (N+1, 인덱스)

### 보안 취약점 검증

```markdown
## XSS 방지 검증
검사 대상: 입력값 처리 및 출력 렌더링 로직

검출된 위험:
- {파일명}:{라인} - 입력값 이스케이프 누락

## SQL Injection 방지 검증
검사 대상: 쿼리 생성 부분

검출된 위험:
- {파일명}:{라인} - 입력값 이스케이프 누락
```

### 성능 이슈 검증

```markdown
## 쿼리 성능 검증
- [ ] N+1 쿼리 문제 존재 여부
- [ ] 인덱스 없는 컬럼 WHERE 절 사용
- [ ] SELECT * 사용 (필요한 컬럼만 선택)

검출된 이슈:
- {파일명} - N+1: 루프 안에서 findById() 반복 호출

개선 방안:
- WHERE IN 절로 일괄 조회로 변경
```

## 에러 패턴 분류 상세

### 유형 1: 규칙 망각 (Rule Forgetting)
```markdown
패턴: {프로젝트 규칙 위반 사례}
빈도: 이번 작업에서 {N}회 발생
원인: 다른 프로젝트 경험으로 인한 습관

대응:
- Spec 문서에 규칙 강조 추가
- Test 단계에서 검증 테스트 케이스 추가
```

### 유형 2: 불완전한 이해 (Incomplete Understanding)
```markdown
패턴: {누락된 설정/업데이트 사례}
빈도: {특정 작업 유형}에서 매번
원인: Post-Implementation 단계를 생략

대응:
- /run 커맨드에 체크리스트 추가
- 필수 단계로 강조
```

### 유형 3: 복사-붙여넣기 실수 (Copy-Paste Errors)
```markdown
패턴: 클래스명/네임스페이스 수정 누락
빈도: 기존 코드 참조 시 자주 발생
원인: 템플릿 코드 복사 후 일부만 수정

대응:
- 이름/경로 일치 검증 추가
- IDE 자동 생성 기능 활용 권장
```
