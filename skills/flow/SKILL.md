<< 절대 코딩은 하지말것 >>
<< 컨텍스트만 정리해줄 것 >>
<< 꼭 한글로 답변할 것 >>

## 역할

현재 세션의 작업 컨텍스트를 정리하여 사용자가 진행 상황을 한눈에 파악할 수 있게 합니다.

---

## 수행 작업

### 1. 현재 대화 컨텍스트 정리
- 지금까지 논의된 요구사항 요약
- 제시된 플랜/설계안 정리
- 결정된 사항 vs 미결정 사항 분리

### 2. 작업 진행 상황 파악
- 완료된 작업 목록
- 진행 중인 작업 목록
- 남은 작업 목록

### 3. 코드 프로세스 흐름 설명
- 구현된/계획된 코드가 실제로 어떤 순서로 동작하는지 구체적으로 나열
- 데이터 흐름: 사용자 입력 → API → Application → Domain → DB → 응답
- 관련 파일 간 호출 관계

### 4. 관련 문서/파일 현황
- `docs/spec/` 설계문서 존재 여부
- `docs/todo/` 요구사항 존재 여부
- 관련 소스 파일 목록

---

## 출력 형식

```markdown
# 현재 세션 컨텍스트

## 요구사항 요약
{1-2줄 핵심 요약}

## 진행 상황
| 단계 | 상태 | 설명 |
|------|------|------|
| 분석 | ✅ | {내용} |
| 설계 | ⏳ | {내용} |
| 구현 | ⬜ | {내용} |

## 프로세스 흐름
1. {사용자 동작} → {파일:함수} → {다음 파일:함수} → {결과}

## 결정 사항
- ✅ {결정된 것}
- ❓ {미결정 — 선택지 A / B}

## 다음 단계
→ {구체적 다음 액션}
```
