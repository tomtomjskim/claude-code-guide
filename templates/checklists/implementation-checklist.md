# 구현 체크리스트

## 1. 구현 전 확인
- [ ] 설계 문서를 확인했는가?
- [ ] 관련 기존 코드를 분석했는가?
- [ ] 인터페이스/타입 정의를 확인했는가?
- [ ] 테스트 계획을 확인했는가?

## 2. 코드 품질
- [ ] 설계를 정확히 준수했는가?
- [ ] 타입이 적절히 정의되었는가?
- [ ] any 타입을 사용하지 않았는가?
- [ ] 중복 코드가 없는가?
- [ ] 함수/메서드가 단일 책임을 가지는가?

## 3. 네이밍 컨벤션
- [ ] 변수명이 명확한가?
- [ ] 함수명이 동작을 설명하는가?
- [ ] 프로젝트 네이밍 규칙을 따르는가?

## 4. 에러 핸들링
- [ ] 예외 처리가 적절한가?
- [ ] 에러 메시지가 명확한가?
- [ ] 사용자 친화적 에러 표시가 구현되었는가?
- [ ] 에러 로깅이 구현되었는가?

## 5. 보안
- [ ] 입력 검증이 구현되었는가?
- [ ] SQL Injection 방지가 되었는가?
- [ ] XSS 방지가 되었는가?
- [ ] 인증/인가가 구현되었는가?

## 6. 성능
- [ ] 불필요한 리렌더링이 없는가?
- [ ] 쿼리가 최적화되었는가?
- [ ] 적절한 캐싱이 적용되었는가?

## 7. 테스트
- [ ] 단위 테스트를 작성했는가?
- [ ] 엣지 케이스를 테스트했는가?
- [ ] 에러 케이스를 테스트했는가?
- [ ] 테스트가 모두 통과하는가?

## 8. 접근성 (UI)
- [ ] 키보드 네비게이션이 가능한가?
- [ ] 스크린 리더 지원이 되는가?
- [ ] 색상 대비가 적절한가?

## 9. 반응형 (UI)
- [ ] 모바일 화면에서 정상 동작하는가?
- [ ] 태블릿 화면에서 정상 동작하는가?
- [ ] 데스크톱 화면에서 정상 동작하는가?

## 10. 문서화
- [ ] 복잡한 로직에 주석이 있는가?
- [ ] API 문서가 업데이트되었는가?
- [ ] 태스크 문서가 업데이트되었는가?

## 구현 완료 전 최종 확인
```bash
# 린트 검사
npm run lint

# 타입 검사
npm run type-check

# 테스트 실행
npm run test

# 빌드 확인
npm run build
```

- [ ] 불필요한 주석 제거
- [ ] 포매팅 적용 (prettier)
