# Agent Operating Kernel Adapter for Claude Code

```yaml
template_id: agent-operating-kernel
template_version: 0.1.0
adapter: claude-code
adapter_version: 0.1.0
applied_at:
```

이 템플릿은 Fable류 작업방식을 흉내 내는 프롬프트가 아니라, 위험도가 높은 작업에서만 켜는 운영 계약이다. 프로젝트의 기존 `CLAUDE.md`에 필요한 항목만 복사한다.

## 적용 조건

다음 중 하나라도 해당하면 이 어댑터를 적용한다.

- 보안, 인증, 결제, 투자, 배포, 데이터 삭제/이전 작업
- 런북, 복구, 운영 자동화, launchd/systemd, 서버 이전 작업
- 여러 파일 또는 여러 시스템 경계를 동시에 건드리는 변경
- 모델 출력, 외부 문서, 오래된 로컬 문서의 사실성이 중요한 작업

낮은 위험도의 단일 파일 수정, 단순 설명, 빠른 탐색에는 적용하지 않는다.

## 실행 계약

- 시작 전에 `Scope`, `Non-goals`, `Writable paths`, `Done criteria`, `Verification`을 짧게 선언한다.
- 외부 입력, 모델 출력, 오래된 문서, 환경변수, API 응답, DB 스키마는 검증 전까지 신뢰하지 않는다.
- 날짜, 버전, 모델명, 가격, 정책, API 동작처럼 변할 수 있는 사실은 출처와 확인 시점을 남긴다.
- 결정은 머릿속에 두지 않고 `D1`, `D2`처럼 ID를 붙여 이유, 비용, 되돌리는 방법을 기록한다.
- 변경은 기존 구조 위에 얹는 것을 기본값으로 한다. 갈아엎는 방식은 대안과 롤백 경로가 있을 때만 선택한다.
- 팀/병렬/리뷰어 에이전트는 독립 하위문제가 있거나 blast radius가 큰 경우에만 사용한다.

## 승인 게이트

사용자 승인 없이 진행하지 않는다.

- destructive command 또는 되돌리기 어려운 파일/데이터 변경
- 배포, 마이그레이션, launchd/systemd 등록, 원격 서버 설정 변경
- 실전 키, 비밀값, 토큰, 인증서의 저장/전송/노출
- 비용이 발생하거나 외부 API 호출량이 커지는 작업

## 완료 증거

완료 보고에는 최소한 다음을 포함한다.

- 변경한 파일 또는 설정 위치
- 실행한 검증 명령과 결과
- 남은 수동 단계
- 롤백 또는 복구 경로
- 갱신해야 할 문서가 있으면 해당 위치

## 버전 관리

- `template_version`은 운영 커널 계약 버전이다.
- `adapter_version`은 Claude Code용 표현과 설치 방식 버전이다.
- 이 버전은 `agents.yaml`의 팀 시스템 버전과 별개로 관리한다.
