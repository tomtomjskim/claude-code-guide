# 초보자 치트시트

> Claude Code를 처음 쓸 때 이것만 알면 됩니다

---

## 기본 대화

| 하고 싶은 것 | 이렇게 말하세요 |
|-------------|---------------|
| 파일 읽기 | "index.html 파일 보여줘" |
| 파일 수정 | "제목을 '안녕하세요'로 바꿔줘" |
| 파일 만들기 | "about.html 파일을 만들어줘" |
| 버그 수정 | "글씨가 안 보여, 고쳐줘" |
| 설명 요청 | "이 코드가 뭐 하는 건지 설명해줘" |
| 되돌리기 | "방금 변경 취소해줘" |

## 알아두면 좋은 명령어

| 명령어 | 뜻 | 사용 예 |
|--------|-----|---------|
| `/dispatch` | 접수처에 업무 요청 | `/dispatch "메뉴 색상 변경"` |
| `/run` | 바로 실행 | `/run "버튼 추가해줘"` |

## Git 최소 개념

| 용어 | 쉽게 말하면 |
|------|-----------|
| commit | "저장 + 메모" |
| git log | "저장 기록 보기" |
| git checkout | "이전 버전으로 돌아가기" |

## 실수했을 때

```
# 방금 한 변경을 되돌리고 싶을 때
git checkout -- 파일이름

# 모든 변경을 되돌리고 싶을 때
git checkout .
```

## 팁
- 코드를 몰라도 됨 — **"뭐가 이상한지"만 말하면** Claude가 고침
- 한 번에 여러 요청 가능 — "제목 바꾸고, 색도 바꿔줘"
- 실수해도 안전 — Git으로 언제든 원복 가능
