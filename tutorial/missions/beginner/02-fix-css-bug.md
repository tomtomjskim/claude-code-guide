# 미션 2: CSS 버그 고치기 — "이거 왜 안 보여요?"

> 예상 소요: 3분 | 난이도: ★★☆☆☆

## 목표
Claude Code에게 화면 문제를 설명하고, 코드를 고쳐달라고 한다.

## 배경
`hello-world/index.html`을 브라우저에서 열어보면 문제가 보입니다:
- 헤더 아래 부제목 글씨가 안 보임
- "이 페이지 열어보기"에 취소선 대신 밑줄이 있음
- 메모 글씨가 너무 작음

코드를 몰라도 괜찮습니다. **"어디가 이상한지"만 말하면** Claude가 고칩니다.

## 실습

### Step 1: 브라우저에서 확인
```bash
open index.html
```
(또는 파일을 더블클릭해서 브라우저로 열기)

### Step 2: 문제 설명하기
Claude Code에게 이렇게 말해보세요:

```
index.html을 브라우저에서 열었는데 문제가 3개 있어:
1. 헤더 아래 부제목 글씨가 배경색에 묻혀서 안 보여
2. "이 페이지 열어보기"에 완료 표시(취소선)가 아니라 밑줄이 그어져 있어
3. 메모 영역 글씨가 너무 작아

고쳐줘
```

### Step 3: 변경 내용 확인하기
Claude가 `style.css` 파일을 수정할 것입니다.
수정 후 브라우저를 새로고침해서 확인하세요.

### Step 4: 되돌리기 (선택사항)
원래대로 복구하고 싶다면:
```
이전 변경 취소해줘
```
또는 터미널에서:
```bash
git checkout -- style.css
```

## 성공 기준
- [x] 부제목이 보인다 (흰색 또는 밝은 색)
- [x] 완료 항목에 취소선(~~text~~)이 적용된다
- [x] 메모 글씨 크기가 읽기 편하다

## 이번 미션에서 배운 것
- **문제를 "말"로 설명하면** Claude가 코드를 고친다
- 코드를 직접 읽거나 수정할 줄 몰라도 된다
- `git checkout`으로 언제든 원래 상태로 돌아갈 수 있다 (안전!)
