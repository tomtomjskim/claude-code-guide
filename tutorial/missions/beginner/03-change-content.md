# 미션 3: 내용 바꿔보기 — "내 걸로 만들기"

> 예상 소요: 3분 | 난이도: ★★☆☆☆

## 목표
Claude Code에게 웹페이지 내용을 자신만의 것으로 바꿔달라고 한다.

## 배경
코드를 몰라도 **"이 내용을 이걸로 바꿔줘"** 하면 됩니다.
마치 동료에게 문서 수정을 부탁하는 것과 같습니다.

## 실습

### Step 1: 내용 바꾸기
Claude Code에게 이렇게 말해보세요 (자신의 내용으로 바꿔서):

```
hello-world 페이지를 내 취향으로 바꿔줘:
- 제목을 "OOO의 페이지"로 바꿔줘
- 할 일 목록을 내 오늘 할 일로 바꿔줘: 아침 운동, 점심 약속, 보고서 작성
- 좋아하는 것들을 바꿔줘: 여행, 독서, 요리, 영화
- 메모에 "오늘도 좋은 하루!" 라고 써줘
```

### Step 2: 결과 확인
브라우저를 새로고침해서 바뀐 내용을 확인하세요.

### Step 3: 추가 요청 (자유롭게!)
더 바꾸고 싶은 게 있다면 자유롭게 요청해보세요:
```
배경색을 연분홍으로 바꿔줘
```
```
카드를 하나 더 추가해줘. 제목은 "목표"이고 내용은 "올해 안에 코딩 배우기"
```

## 성공 기준
- [x] 페이지 내용이 나만의 것으로 바뀌었다
- [x] 추가 요청도 해봤다

## 이번 미션에서 배운 것

- 한 번에 여러 변경을 요청해도 된다
- 추가 요청으로 점점 원하는 모습을 만들어갈 수 있다
