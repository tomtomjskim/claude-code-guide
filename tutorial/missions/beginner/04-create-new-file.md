# 미션 4: 새 파일 만들기 — "이런 페이지 만들어줘"

> 예상 소요: 3분 | 난이도: ★★★☆☆

## 목표
Claude Code에게 새로운 파일을 처음부터 만들어달라고 한다.

## 배경
지금까지는 기존 파일을 읽거나 수정했습니다.
이번에는 **아무것도 없는 상태에서** 새로운 것을 만들어봅니다.

## 실습

### Step 1: 새 페이지 요청
Claude Code에게 이렇게 말해보세요:

```
hello-world 폴더에 about.html 파일을 만들어줘.
자기소개 페이지인데:
- 이름, 한 줄 소개
- 취미 3가지 (아이콘이나 이모지 포함)
- 좋아하는 명언 하나
- index.html로 돌아가는 링크
스타일은 style.css를 같이 사용하게 해줘
```

### Step 2: 결과 확인
```bash
open about.html
```

### Step 3: index.html에 연결 요청
```
index.html에서 about.html로 갈 수 있는 링크도 추가해줘.
헤더 부분에 "소개 페이지" 링크를 넣어줘.
```

## 성공 기준
- [x] about.html 파일이 생성되었다
- [x] 브라우저에서 열어볼 수 있다
- [x] index.html에서 about.html로 이동할 수 있다

## 이번 미션에서 배운 것
- Claude Code는 **새 파일을 만들 수 있다**
- 원하는 내용을 말로 설명하면 코드를 생성해준다
- 파일 간의 연결(링크)도 요청할 수 있다
