# 미션 1: 첫 대화 — "이 파일이 뭐예요?"

> 예상 소요: 2분 | 난이도: ★☆☆☆☆

## 목표
Claude Code에게 파일 내용을 물어보고, 대답을 받아본다.

## 배경
Claude Code는 일반 챗봇과 다릅니다.
**파일을 직접 읽고, 수정하고, 만들 수 있는 AI 동료**입니다.

## 실습

### Step 1: 샌드박스로 이동
터미널에서 아래 명령을 입력하세요:
```bash
cd tutorial/sandbox/hello-world
```

### Step 2: Claude Code에게 질문하기
Claude Code에 이렇게 말해보세요:

```
index.html 파일이 뭘 하는 파일인지 설명해줘
```

### Step 3: 결과 확인
Claude가 파일을 읽고 내용을 설명해줄 것입니다.
- HTML 구조를 설명하나요?
- 어떤 섹션이 있는지 알려주나요?

## 성공 기준
- [x] Claude가 index.html의 내용을 읽고 설명해준다
- [x] "헤더", "카드", "할 일 목록" 같은 구조를 언급한다

## 이번 미션에서 배운 것
- Claude Code는 파일을 직접 읽을 수 있다
- 자연스러운 한국어로 질문하면 된다
- 코드를 몰라도 "이게 뭔지" 물어볼 수 있다
