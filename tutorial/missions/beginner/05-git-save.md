# 미션 5: Git으로 저장하기 — "작업 기록 남기기"

> 예상 소요: 3분 | 난이도: ★★★☆☆

## 목표
지금까지 한 작업을 Git으로 저장(커밋)하고, 기록을 확인한다.

## 배경

### Git이 뭔가요?
**문서의 "버전 히스토리"** 같은 것입니다.

구글 독스에서 `파일 > 버전 기록`을 열면 과거 버전을 볼 수 있죠?
Git도 똑같습니다. 다만 모든 파일을 한꺼번에 추적합니다.

| 구글 독스 | Git |
|-----------|-----|
| 자동 저장 | `git add` + `git commit` (의도적 저장) |
| "버전 기록 보기" | `git log` |
| "이 버전으로 복원" | `git checkout` |
| 설명 메모 | 커밋 메시지 ("CSS 버그 수정") |

### 왜 중요한가요?
- 실수해도 이전 상태로 돌아갈 수 있다
- "언제 뭘 바꿨는지" 기록이 남는다
- 여러 사람이 같은 프로젝트에서 일할 수 있다

## 실습

### Step 1: 변경 내역 보기
Claude Code에게:
```
지금까지 어떤 파일이 변경되었는지 보여줘
```

### Step 2: 저장(커밋)하기
```
변경된 파일들을 Git으로 저장해줘. 메시지는 "튜토리얼: 첫 번째 수정 완료"로 해줘
```

### Step 3: 기록 확인하기
```
Git 히스토리 보여줘
```

### Step 4: 되돌리기 체험 (선택)
```
방금 커밋을 취소하고 이전 상태로 돌아갈 수 있어?
```
(Claude가 방법을 설명해줄 것입니다. 실제로 해볼지는 선택!)

## 성공 기준
- [x] `git log`에 내 커밋이 보인다
- [x] 커밋 메시지가 포함되어 있다

## 이번 미션에서 배운 것
- Git = 파일의 "버전 히스토리"
- **커밋** = "이 시점을 기억해둬" (저장 + 메모)
- Claude Code에게 Git 작업도 맡길 수 있다
- 언제든 이전 상태로 돌아갈 수 있다 → **실험이 안전하다!**
