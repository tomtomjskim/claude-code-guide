## Summary

v4.2는 **DESIGN.md 운영 모델** 릴리즈이다. v4.1이 외부 사용자 진입과 Hook 신뢰성을 정리했다면, v4.2는 UI 작업에서 에이전트가 재사용할 수 있는 시각 디자인 계약을 표준화한다.

핵심 변화:
- `DESIGN.md`를 `CLAUDE.md`/`AGENTS.md`와 분리된 시각 시스템 문서로 정의
- Google `design.md` 스펙을 토큰 구조의 기준으로 채택
- VoltAgent/getdesign.md 계열 예시는 레퍼런스와 설명 밀도로만 차용
- 대상 프로젝트에 주입 가능한 `DESIGN-template.md`와 체크리스트 추가
- UI 작업 전 `DESIGN.md` 확인 규칙을 디자인 모드에 연결

## Versioning

`DESIGN.md`는 각 대상 프로젝트의 문서이므로 레포 전체 버전과 분리한다.

| 변경 유형 | 예시 | 권장 버전 |
|---|---|---|
| Patch | 설명 보강, 누락 상태 추가 | `0.1.1` |
| Minor | 신규 토큰/컴포넌트 추가 | `0.2.0` |
| Major | 토큰명 제거, spacing scale 변경, 브랜드 리뉴얼 | `1.0.0` 또는 사용자 승인 |

## Migration

기존 사용자에게 필수 migration은 없다. UI 작업이 있는 프로젝트에는 다음 파일을 선택적으로 주입한다.

```bash
cp templates/docs/DESIGN-template.md /path/to/project/DESIGN.md
cp templates/checklists/design-md-checklist.md /path/to/project/docs/design-md-checklist.md
```

기존 디자인 시스템이 있는 프로젝트는 템플릿 값을 그대로 쓰지 말고 CSS 변수, Tailwind config, component library에서 현재 값을 먼저 추출한다.
