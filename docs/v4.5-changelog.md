# Claude Code Guide v4.5 Changelog

**Release Date**: 2026-07-28
**Upgraded From**: v4.4
**Research Source**: `affaan-m/ECC@4e973d3`

## Added

- source ref pinning과 moving-main 경고
- install-state 기반 `doctor`, `repair`, `uninstall`
- 이전·설치 payload hash/mode 검증과 state path traversal 차단
- finalize 이전 설치 단계 실패 시 begin snapshot 기반 자동 rollback
- 임시 HOME/target 기반 lifecycle 회귀 테스트
- portable source surface validator
- ECC 선별 도입 결정과 비채택 경계 문서

## Changed

- 로컬 `quick-setup.sh`는 원격 main을 다시 clone하지 않고 현재 checkout을 사용한다.
- enterprise validation은 project와 Claude home을 명시해 실제 설치 위치를 검사한다.
- `CLAUDE_CONFIG_DIR`를 사용하면 team install, validation, lifecycle state가 같은
  Claude home을 사용한다.
- enterprise validation 실패 전에도 install-state를 확정해 제거 가능한 상태를
  보존한다.
- settings template의 개인 절대 경로를 placeholder로 바꿨다.

## Migration

기존 설치는 자동으로 관리 상태로 간주하지 않는다. v4.5 `quick-setup.sh`를 성공적으로
실행한 설치부터 install-state가 생긴다. 기존 사용자 파일은 `--force` 없이는
덮어쓰지 않는다.
