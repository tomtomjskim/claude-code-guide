# Multi-Agent Team System v4.5 Changelog

**Release Date**: 2026-06-15
**Upgraded From**: v4.4 (2026-05-19, external agent skill adoption)

---

## Summary

v4.5는 **Agent Operating Kernel adapter** 릴리즈이다. `stock-auto`에서 관찰한 Fable류 작업방식의 장점, 즉 불신 기본값, 결정 증거화, 경계 선언, 가역성, 넓은 완료 기준을 Claude Code 프로젝트에 선택적으로 적용할 수 있게 했다.

핵심 원칙은 "모델 흉내"가 아니라 "위험도 기반 운영 계약"이다. 일반 작업은 기존 Claude Code/PDARR 흐름을 유지하고, 보안/운영/데이터/배포처럼 실패 비용이 큰 작업에서만 커널 어댑터를 켠다.

## Adapter Scope

`templates/CLAUDE.kernel.md`는 프로젝트의 기존 `CLAUDE.md`에 필요한 항목만 복사해서 쓰는 선택 템플릿이다. `templates/CLAUDE.kernel-evaluation.md`는 시험 적용 후 practical mode 대비 효과와 비용을 비교하는 기록 양식이다.

적용 대상:
- 보안, 인증, 결제, 투자, 배포, 데이터 삭제/이전
- 런북, 복구, launchd/systemd, 서버 이전
- 여러 파일 또는 여러 시스템 경계를 건드리는 변경
- 최신성 또는 사실성이 중요한 모델/문서/API 판단

비적용 대상:
- 낮은 위험도의 단일 파일 수정
- 단순 설명, 빠른 탐색, 작은 문서 정리
- 모델 성향을 모든 작업에 강제하는 전역 프롬프트

## Versioning

커널과 어댑터 버전은 분리한다.

| 필드 | 의미 |
|---|---|
| `template_id` | 공통 운영 계약 ID |
| `template_version` | 공통 커널 계약 버전 |
| `adapter` | 도구별 적용 대상 |
| `adapter_version` | Claude Code용 표현과 설치 방식 버전 |

이 버전은 `agents.yaml` 팀 시스템 버전과 별개이다. 커널 변경이 곧 에이전트 라우팅 변경을 뜻하지 않고, 에이전트 라우팅 변경이 곧 커널 계약 변경을 뜻하지 않는다.

## Migration

필수 migration 없음.

고위험 프로젝트에서만 다음처럼 적용한다.

```bash
cp templates/CLAUDE.kernel.md /path/to/project/docs/CLAUDE.kernel.md
```

그다음 프로젝트의 `CLAUDE.md`에 필요한 조항만 링크하거나 복사한다. hook, skill, agent routing을 자동으로 추가하지 않는다.

시험 적용 후에는 다음 템플릿으로 비교 평가를 남긴다.

```bash
mkdir -p /path/to/project/docs/evaluations/agent-operating-kernel
cp templates/CLAUDE.kernel-evaluation.md /path/to/project/docs/evaluations/agent-operating-kernel/YYYY-MM-DD-{project}-{task}.md
```
