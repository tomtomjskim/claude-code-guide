## Summary

- **PM 검수 통과**: 15 항목 (4 HIGH + 6 MEDIUM + 5 LOW) 전수 처리, GREEN 판정

**범위 밖 (의도적 out-of-scope):**

- 버전 숫자 bump 없음 (`agents.yaml:4` `version: "3.2"` canonical 유지)

### 2. Hook 시스템 신뢰성 — Bundle H 시리즈 (5 커밋)

사용자 직접 critique 10건 + PM 검수 15건 = **총 25 항목** 처리.

| Bundle | 커밋 | 처리 항목 |
|--------|------|----------|
| **H-P0** | [c5c111a](../commit/c5c111a) | 버그 4건 (rm 앵커, dev bypass, trap ERR, argv literal) |
| **H-P1** | [bec2bcf](../commit/bec2bcf) | 오탐 축소 4건 (2-tier 매칭, heuristic 명시, 영속 로그, grep_compat) |
| **H-P2** | [8049c74](../commit/8049c74) | 정책·구조 명시 3건 (fail 정책, 네임스페이스, BLOCKED_TYPES 의도) |
| **H-P3** | [99010dd](../commit/99010dd) | MAX_AGENT_CALLS 완화 + PM HIGH 4건 |
| **H-P4** | [d0e2613](../commit/d0e2613) | PM MEDIUM 5건 + LOW 5건 |

**핵심 개선:**

1. **`rm -rf /` 패턴 앵커** (H-P0 P0-H1) — 기존 패턴이 `/tmp/foo` 같은 정상 절대경로도 매칭하던 오탐 제거. 앵커 `/([[:space:]]|$|\*)` 추가하여 진짜 루트 삭제만 차단.

2. **Dev mode bypass** (H-P0 P0-H2) — `echo "rm -rf /"` 같은 문자열 인자를 hook이 차단하여 hook 자체를 AI가 디버깅·문서화하는 행위가 봉쇄되던 자기모순 해소. `CLAUDE_HOOK_TEST=1` 또는 `.claude/hooks/bypass` 파일로 우회.

3. **argv literal 모드** (H-P0 P0-H4) — first token이 `echo`/`printf`/`#`(주석)이고 shell chaining(`&&`, `;`, `| shell`, `$()`) 없으면 위험 패턴이 문자열 리터럴로 간주되어 차단 스킵. `echo "rm -rf /"` 통과, `echo; rm -rf /` 차단.

4. **2-tier ANALYSIS 매칭** (H-P1 P1-H5) — guard-agent의 단일 한국어 동사("확인해 봐", "파악해", "살펴봐") 단독 매칭으로 정상 prompt가 차단되던 오탐 축소. STRONG 단독 차단 / WEAK + SCOPE_HINT 조합만 차단 구조.

5. **MAX_AGENT_CALLS 완화** (H-P3 P2-H12) — 기본 10에서 50으로 (env override 가능). PM 오케스트레이션(specialist 5+ + retry)에서도 작동.

6. **safety-freeze.sh Tier 2 4분기** (H-P3 P2-H2) — 기존 Tier 2가 절대경로/basename 2분기만 → Tier 1 동일 4분기 (와일드카드/디렉토리/절대경로/basename) 적용. `FROZEN_TIER2=("config/")` silent skip 버그 해소.

7. **quick-setup.sh `eval` 제거** (H-P3 P2-H3) — `run() { eval "$@" }` 패턴이 외부 사용자 ingress(curl|bash)에서 메타문자 처리 위험 → 배열 기반 `run cmd arg1 arg2 ...` 안전 expansion.

8. **`set -eo pipefail`** (H-P3 P2-H4) — `git clone | tail -3` 실패가 silent였던 문제 해결.

## Migration

v4.0 → v4.1 마이그레이션 **불필요** (non-breaking).

기존 사용자가 hook 자체를 개발/테스트/문서화하던 중이라면:

```bash
# 권장: 환경변수 기반 (세션 scope)
export CLAUDE_HOOK_TEST=1

# 또는 파일 기반 (프로젝트 scope)
touch .claude/hooks/bypass
```

기존 v4.0 설치본은 그대로 작동하며, 새 hook 기능을 받으려면:

```bash
bash scripts/install-skills.sh --team --force <target>
bash scripts/install-hooks.sh --force <target>
```
