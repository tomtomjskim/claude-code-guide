## Summary

v4.7은 **Shared Agent Rules** 릴리즈이다. Claude Code와 Codex가 전역 agent 역할 규칙을 같은 원천에서 참조하도록 `~/.agents` 기반 구조를 표준화한다.

핵심은 프로젝트 내부 agent를 유지하고, 전역 agent에는 프로젝트 특화 규칙을 넣지 않는 것이다.

## Key Decisions

### Project agents stay project-local

Frecto, WMS 등 프로젝트 특화 agent는 각 repo 내부 `.claude/agents/`와 `.codex/agents/`에 둔다. 전역 agent에는 공통 역할 계약만 둔다.

### `~/.agents` is the shared source

권장 구조:

```text
~/.agents/common-agents/
~/.agents/adapters/claude/
~/.agents/adapters/codex/
```

Claude와 Codex adapter는 각 런타임 형식만 담당하고, 역할 규칙은 `common-agents/`를 참조한다.

### `~/.claude/agents` should be symlinks

`install-skills.sh --team`은 더 이상 repo agent를 `~/.claude/agents`에 직접 복사하지 않는다. `~/.agents/adapters/claude`에 복사한 뒤 symlink를 만든다.

---

## Migration

필수 migration 없음.

권장 적용:

1. 프로젝트 내부 agent는 유지한다.
2. 기존 전역 agent는 백업한다.
3. 공통 역할은 `~/.agents/common-agents/`에 둔다.
4. Claude adapter는 `~/.agents/adapters/claude/`, Codex adapter는 `~/.agents/adapters/codex/`에 둔다.
5. `~/.claude/agents`와 `~/.codex/agents`는 symlink로 연결한다.
