# Multi-Agent Team System v4.4 Changelog

**Release Date**: 2026-05-19
**Upgraded From**: v4.3 (2026-05-12, PDARR + Goal-runtime 정렬)
**Strategy Source**: `mattpocock/skills` adoption review

---

## Summary

v4.4는 외부 agent skill 패턴을 기존 PDARR 스킬에 흡수하는 운영 업데이트이다.
새 스킬을 대량 추가하지 않고, `diagnose`, `zoom-out`, tracer bullet TDD,
project context 설정을 기존 스킬과 문서에 연결했다.

---

## Guardrails

- GitHub issue/label/comment write는 dry-run과 사용자 확인을 기본값으로 둔다.
- raw wiki나 raw 작업 메모를 공개 도메인 뷰어에 복사하지 않는다.
- prototype은 폐기, 실제 구현 흡수, 후속 task 생성 중 하나로 끝낸다.
- tracer bullet TDD는 실패 확인 없이 green-only 테스트를 추가하지 않는다.

---

## Migration

기존 프로젝트에 필수 migration은 없다. 새 설치 또는 setup-wizard 실행 시 project
context 질문을 채워 두면 `/analyze`, `/test`, `/qa-test`가 더 안정적으로 동작한다.
