## Key Decisions

### `다음 추천 작업` is candidate backlog

`다음 추천 작업`은 자동 진행 지시가 아니다. 완료를 막는 항목만 `필수`로 두고,
품질 개선은 `선택`, 새 목표나 승인 필요 항목은 `보류`로 분리한다.

### Audit before continuing long-running work

장기 goal, resume, 반복 "계속 진행" 요청에서는 구현 전에 `/goal-audit`로 상태를
판정한다. 권고는 `continue`, `complete`, `block`, `replan`, `handoff` 중 하나만
반환한다.

### Pilot in a new docs-only project

WMS 같은 기존 dirty worktree를 건드리지 않는다. `/Users/jeongsik/dev/goal-audit-pilot`
같은 새 docs-only 프로젝트에서 기대 결과와 실제 결과를 비교한다.

## Migration

필수 migration 없음.

권장 적용:

1. 대상 프로젝트에 `bash scripts/install-skills.sh --skills goal-audit <target>`로
   스킬을 설치한다.
2. 장기 작업 프롬프트에 성공 기준, stop condition, validation, expected/actual
   result를 포함한다.
3. 첫 checkpoint 또는 resume 전에 `/goal-audit`를 호출한다.
